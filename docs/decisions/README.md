## What is an Architecture Decision Record (ADR)?

An **Architecture Decision Record (ADR)** is a lightweight document capturing an important architectural choice made on this project, along with its context, options considered, rationale, and consequences.

Future student leaders and developers should refer to this directory before proposing major architectural shifts.
