# 11 — Challenges, Hackathons & Competitive Sprints

**Product**: ACE UiPath Community Digital Operating System  
**Category**: Competitive Automation & Talent Identification  

---

## 1. Challenge Formats

The platform supports four competitive sprint models (`/challenges`):
1. **Flagship Enterprise Hackathon**: 24–48 hour high-stakes competition with cash prizes (₹25,000+), industry judges, and real enterprise problem statements.
2. **Monthly Bot Sprint**: 2-week agile challenges focused on a specific UiPath capability (e.g. Resume parsing with Document Understanding, Web scraping with Modern Selectors).
3. **Ideation & Architecture Sprint**: Problem-framing competition where students design RPA solution blueprints and feasibility studies before writing code.
4. **Automation Bug Bash**: Debugging marathon where students find and fix intentional errors in complex REFramework state machines.

---

## 2. Competitive Lifecycle Management

```text
1. UPCOMING     Announcement, countdown timer, prize pool, team registration open.
     │
     ▼
2. ACTIVE       Problem statements and sample datasets released; submissions open.
     │
     ▼
3. JUDGING      Submissions closed; jury reviews GitHub repos & 3-minute video demos.
     │
     ▼
4. COMPLETED    Official results published; winning teams added to Hall of Champions.
```

---

## 3. Team Submission & Evaluation Pipeline

- **Submission Payload**: Team Name, Team Members & Roll Numbers, Project Title, GitHub Repo / Cloud Package URL, 3-Minute Video Demonstration URL.
- **Scoring Rubric Matrix**:
  - Business Value & Practical ROI (30%)
  - UiPath Architecture & REFramework Best Practices (30%)
  - Robust Exception Handling & Auto-Recovery (20%)
  - Code Cleanliness, Annotations & README Documentation (20%)
