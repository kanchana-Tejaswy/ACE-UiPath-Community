# 17 — Content Lifecycle & Archival Governance

**Product**: ACE UiPath Community Digital Ecosystem  
**Core Governance Rule**: Permanent Archival Over Destruction  

---

## 1. Content Lifecycle Stages

```text
Draft ──► Review ──► Approved ──► Published ──► Featured ──► Archived ──► Preserved Permanently
```

1. **Draft**: Initial event concept or student bot submission created by Core Team or Student.
2. **Review**: Content in Core Team / Admin queue awaiting validation.
3. **Approved**: Validated and ready for scheduling/publication.
4. **Published**: Live on public website and timeline.
5. **Featured**: Promoted to Homepage Hero or Spotlight Carousel.
6. **Archived**: Completed event or legacy content moved to historical archives.
7. **Preserved Permanently**: Read-only permanent record in institutional memory database.

---

## 2. Archival vs Deletion Policy

> **Historical activities and student automations must GENERALLY NEVER be permanently deleted.**

Permanent deletion destroys institutional history. When an activity concludes, its status shifts from `Upcoming` → `Completed` → `Archived`, preserving session agendas, slide decks, video recordings, `.xaml` workflows, and student awards forever.
